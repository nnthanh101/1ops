# 1ops

Runs the [1ops](https://github.com/nnthanh101/1ops) command line from npm. Needs [uv](https://docs.astral.sh/uv/); the matching Python package version is fetched on first run.

```bash
npx 1ops doctor
npx 1ops install --yes
npx 1ops config --scope team --connectors aws azure itsm
```

All commands and scopes are documented in the [Python package README](https://github.com/nnthanh101/1ops/tree/develop/packages/python).
