# 1xops

Runs the `1xops` command line of [1xops](https://github.com/nnthanh101/1xops) from npm. Needs [uv](https://docs.astral.sh/uv/); the matching Python package version is fetched on first run.

```bash
npx 1xops doctor
npx 1xops install --yes
npx 1xops config --scope team --connectors aws azure itsm
```

All commands and scopes are documented in the [Python package README](https://github.com/nnthanh101/1xops/tree/develop/packages/python).
